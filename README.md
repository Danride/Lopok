# Зелёный удел — 2.5D стратегия

Модульная версия прототипа **3.1**. Дом, лесопилка с анимацией пилы, 1–2 жителя на дом, доставка брёвен и строительство на карте.

## Запуск

В папке проекта выполни `py -m http.server 8000` (Windows) или `python -m http.server 8000`. Открой http://localhost:8000/. **Node.js и npm не нужны.** Можно опубликовать этот проект как статический сайт через GitHub Pages.

Важно: при запуске напрямую через `file://` браузер может заблокировать загрузку внешних файлов; Three.js 0.166.1 и GLTFLoader подгружаются с jsDelivr (требуется интернет).

## Папки

- `index.html` — интерфейс и подключение скриптов
- `css/style.css` — оформление
- `js/main.js` — последовательная загрузка
- `js/scene.js` — карта, свет, рендерер
- `js/models.js` — модели и материалы
- `js/buildings.js` — здания, клетки, размеры
- `js/pathfinding.js` — маршруты
- `js/residents.js` — жители, рубка и доставка
- `js/ui.js` — меню строительства и HUD
- `js/camera.js` — камера
- `js/input.js` — управление мышью и касаниями
- `js/save.js` — сохранение в localStorage
- `js/startup.js` — модели, запуск игрового цикла
- `assets/models/*.gltf` — самодостаточные оригинальные GLTF из Blockbench

## Механики

Дом создаёт 1–2 жителя. Лесопилка занимает 2×2 клетки. Житель находит дерево, рубит его и приносит бревно на лесопилку. Только после доставки выдаётся +8 древесины. Дерево даёт три бревна и восстанавливается через 42 секунды. Дома дают монеты. Для старых сохранений сохранён ключ `green_fief_v3`.

## Управление

ЛКМ — строить; ПКМ — вращать камеру; СКМ/Shift+ЛКМ — перемещать; колесо — масштаб; `R` — повернуть здание; `Q/E` — повернуть камеру; `WASD` — перемещение.

## Техническая оговорка

На первом этапе игровые системы разложены по отдельным обычным JS-файлам с **общей глобальной областью видимости**. Это позволяет сохранить исходную логику без переписывания всех взаимных вызовов. Пока это не полноценная архитектура независимых ES-модулей. Для следующего этапа рекомендуется сделать отдельное хранилище состояния и явные зависимости.
